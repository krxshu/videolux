✨ DEPLOYMENT ARCHITECTURE:

  User's Phone Browser
       ↓ (HTTPS Request)
       ↓
  Railway Server (Linux Container)
       ├─ Node.js Runtime
       ├─ Express Server
       ├─ FFmpeg (bundled)
       └─ React Frontend (static files)
       ↓ (Response: HTML/CSS/JS + processed video)
       ↓
  User's Phone Browser (displays app + result)

  Everything on ONE domain = Simple + Secure!

  → Check Railway logs for FFmpeg errors

  CORS errors?
  → Update FRONTEND_ORIGIN to match your domain exactly
